# RabTech SQL Internship – Database Development Projects

## About This Repository

Welcome to my SQL Internship project repository!

This repository contains the tasks and practical implementations completed as part of my **Online SQL Internship at RabTech**.

Throughout this internship, I worked on database design, relational modeling, advanced SQL queries, performance optimization, transaction management, database migrations, automated audit logging, and backup strategies using PostgreSQL.

The objective was to develop practical database skills by implementing real-world database concepts and solving business-oriented problems.

## Internship Tasks

### Task 1 – Business Rules to Executable Relational Model

**Focus:** Database fundamentals and business rule enforcement.

- Identified database entities, states, and relationships.
- Extracted business rules and translated them into database constraints.
- Designed a relational model.
- Implemented primary keys, foreign keys, and constraints.
- Created migration scripts and representative seed data.
- Performed negative SQL tests to verify invalid data rejection.

### Task 2 – Relational Schema Modeling & 3NF Normalization

**Focus:** Database architecture and normalization.

- Designed an Entity-Relationship (ER) model.
- Developed a multi-tenant SaaS database schema.
- Implemented relational tables and relationships.
- Applied Third Normal Form (3NF) normalization.
- Enforced referential integrity.
- Tested database relationships and cascading behavior.

### Task 3 – Advanced SQL Queries, CTEs & Window Functions

**Focus:** Advanced SQL and analytical querying.

- Developed complex SQL queries.
- Used Common Table Expressions (CTEs).
- Implemented window functions.
- Performed analytical calculations.
- Generated business intelligence results from relational data.

### Task 4 – Query Index Tuning, Execution Plans & ACID Transactions

**Focus:** Database performance and transaction reliability.

- Analyzed query execution plans using EXPLAIN ANALYZE.
- Studied database indexing and query optimization.
- Compared query performance.
- Explored ACID transaction properties.
- Implemented and tested transaction behavior.

### Task 5 – Production Database Migration & Backup Strategy Capstone

**Focus:** Production-oriented database management.

- Created version-controlled UP and DOWN migration scripts.
- Implemented automated audit logging using PostgreSQL triggers.
- Developed stored procedures.
- Created standard and materialized views.
- Tested INSERT, UPDATE, and DELETE audit operations.
- Documented database backup and disaster recovery procedures.
